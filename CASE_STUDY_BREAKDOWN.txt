# Case Study: Ayomide Ogunjobi Portfolio
**Role**: Multidisciplinary Designer & AI-Aided Frontend Engineer  
**Project**: 3D Spatial Interactive Portfolio & Multi-Asset Case Study System  
**Stack**: React 18, Vite 5, Pure CSS3 3D Transforms, CSS Custom Properties, IntersectionObserver API  

---

## 1. Executive Summary & Role Context
As a **Multidisciplinary Designer and AI-Aided Developer**, the objective was to design and build an avant-garde, high-performance digital portfolio that bridges the divide between fine art direction, UX/UI product strategy, and modern web engineering.

Rather than relying on generic portfolio templates or heavy WebGL/Three.js engines that bloat bundle sizes and drain mobile battery life, this project engineers a bespoke spatial 3D navigation paradigm using **pure CSS3 3D transforms** and an **authoritative React state machine**.

### Key Accomplishments
- **Zero-Three.js 3D Cube Navigation**: 60fps continuous 3D spatial transitions with a total JavaScript bundle size under 57 kB (gzipped).
- **Context-Adaptive Asset Framing**: Dynamic presentation engine tailored to media types (desktop browser chrome, mobile hardware bezels, museum matte canvas).
- **Kinetic Brand Typography**: 9-personality morphing typography engine celebrating African contemporary, Lagos Danfo, editorial script, and modern brutalist typography.
- **Full Deep-Linking & Accessibility**: Bidirectional hash routing, responsive touch gesture disambiguation, and keyboard-accessible fullscreen lightbox/PDF viewers.
- **AI-Aided Engineering**: Accelerated translation of complex design systems and spatial physics into production-ready, performant frontend code.

### B. Context-Aware Stage Framing System
One size never fits all in multidisciplinary design. Different projects require distinct visual framing:

1. **Browser Window Chrome**:
   - *Applied to*: Web platforms & digital services (*Faem*, *Coldstorm*, *Century Flame*).
   - *Visual Details*: Minimal top bar with traffic light window controls (red/yellow/green), dynamic address pill showing `[project].design`, and live video playback indicator.
2. **Mobile Device Hardware Bezel**:
   - *Applied to*: Mobile apps and UI/UX flows (*Helpa Services*, *Hachi*).
   - *Visual Details*: Hardware mockup featuring 36px rounded corners, speaker notch, and authentic 9:16 aspect ratio framing.
3. **Museum Matte Canvas**:
   - *Applied to*: Brand identities, editorial packaging, and poster artwork (*Ountodun*, *Champion Custard*, *Opn Wrld*, *Awaraku*).
   - *Visual Details*: Elevated museum-grade card featuring hairline borders, generous whitespace, and subtle ambient drop shadows.

## 3. Technical Architecture & Frontend Engineering

### A. Zero-Dependency 3D CSS Engine
- **Pure CSS 3D Transforms**:
  - Parent Container: `perspective: 1200px` with `transform-style: preserve-3d`.
  - Cube Face Positioning: Calculated dynamically using `translateZ(50vw)` (desktop) and `translateZ(50vh)` with mobile media query adjustments.
  - Continuous Angle Accumulation: Rotations increment indefinitely (e.g., `0Â° -> 90Â° -> 180Â° -> 270Â° -> 360Â°`) rather than snapping back to 0, preventing reverse-spin visual glitches.

### B. Face Promotion & Occlusion Architecture
- **The Challenge**: In CSS 3D space, inactive faces can capture pointer events or cause z-index bleeding even when visually occluded.
- **The Solution (Face Promotion Pattern)**:
  - Inactive faces receive `pointer-events: none`, `opacity: 0.15`, and `visibility: hidden`.
  - The active face receives `pointer-events: auto`, `opacity: 1`, and `z-index: 10`.
  - Smooth 0.85s `ease-in-out` cubic-bezier timing ensures flawless visual continuity.

### C. Authoritative State Machine & Gesture Disambiguation
- **Dual-Layer Ref & State Architecture**:
  - React state drives DOM re-renders; companion `useRef` instances hold instantaneous authoritative values for animation flags, cooldown timers, and rotation angles.
- **Wheel & Scroll Disambiguation**:
  - Distinguishes between internal section scrolling and cube face switching.
  - Requires continuous boundary over-scroll (at `scrollTop = 0` or max scroll bottom) exceeding velocity and time thresholds before triggering a 3D transition.
- **Touch Navigation Disambiguation**:
  - Tracks horizontal and vertical swipe deltas, distinguishing between vertical page reading and intentional horizontal cube navigation.

### D. Bidirectional Hash-Based Routing
- Full synchronization between the 3D cube state and URL hash:
  - `#/` &rarr; Hero (Face 0)
  - `#/works` &rarr; Works (Face 1)
  - `#/work/:id` &rarr; Case Study View (e.g., `#/work/opn-wrld`, `#/work/faem`)
  - `#/about` &rarr; About (Face 2)
  - `#/contact` &rarr; Contact (Face 3)
- Includes programmatic navigation guards (`isProgrammaticHashChange.current`) to prevent infinite event loops between user clicks and `hashchange` listeners.

### E. High-Resolution Lightbox & Media Modal System
- **Custom Lightbox Engine**:
  - Supports both images and HTML5 video streaming.
  - Zoom Modes: Native Fit and 1.5x Magnification mode with centered pan framing.
  - Keyboard Navigation: <kbd>Esc</kbd> to close, <kbd>â†</kbd> for previous asset, <kbd>â†’</kbd> for next asset.
  - Filmstrip Thumbnail Rail: Direct jump navigation across multi-image case studies.

### F. Performance & Asset Delivery Optimizations
- Sub-second First Contentful Paint (FCP) and low CPU utilization:
  - **Video Optimization**: Custom lightweight video backgrounds with adaptive streaming and loop/mute flags.
  - **Responsive Picture Elements**: Dual `<picture>` fallbacks and WebP image formats for artwork and packaging studies.
  - **Bundle Metrics**:
    - Total Production CSS: ~40.0 kB (~8.1 kB gzipped)
    - Total Production JS: ~181.3 kB (~56.9 kB gzipped, including React & React Router)
    - Build time: ~2 seconds with Vite.

## 4. AI-Aided Development Workflow & Methodology
This project served as a benchmark for modern AI-assisted product engineering:

### A. Accelerated Ideation to Code
High-level design tokens, layout geometry, and stage framing specifications were translated into modular React functional components and clean CSS custom properties.

### B. Complex Spatial Bug Resolution
Resolved intricate 3D rendering issues through AI pair programming:
1. **3D Face Occlusion & Pointer Hijacking**: Formulated the *Face Promotion Pattern* to ensure zero hit-testing dead zones across 3D planes.
2. **Continuous Angle Math**: Designed the shortest-arc continuous rotation algorithm (delta step math) to eliminate unsightly 270Â° backward spins when cycling between the 4th and 1st faces.
3. **Scroll Locking & Boundary Arbitration**: Built boundary timestamping to prevent scroll jumping on macOS trackpads and mobile touch displays.

### C. Code Integrity & Performance Profiling
AI-aided audits identified legacy static prototypes, unused CSS files, and redundant assets, streamlining the repository into a production-grade codebase.
